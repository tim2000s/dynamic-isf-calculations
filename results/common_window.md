# All four ISF forms on the common window set

Generated by `inv008/common_window.py` from the cached window table of `inv008/head_to_head.py`. Error is observed end glucose minus predicted end glucose (positive: the form predicted too large a fall). Intervals are 95% percentile intervals from 2000 bootstrap draws resampling people.
