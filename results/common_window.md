# All four ISF forms on the common window set

Generated by `inv008/common_window.py` from the cached window table of `inv008/head_to_head.py`. Error is observed end glucose minus predicted end glucose (positive: the form predicted too large a fall). Intervals are 95% percentile intervals from 2000 bootstrap draws resampling people. The windows are the future-rise-selected overnight windows of section 4.3 and the comparison is inside the loop's linear IOB prediction.

Full table: 62,751 windows from 89 people. Common set (V1 and V2 finite): 57,078 windows from 89 people.

## Why windows could not be scored for V1 and V2

- windows without V1 and V2: 5,673 from 30 people; in every one the blended TDD was missing or zero
- Trio (oref_v5), device-logged TDD recorded as zero: 2,309 windows
- Trio (oref_v5), no device TDD within 60 min of the window start: 36 windows
- OpenAPS (oref_v7), reconstructed blend undefined: 3,328 windows; the blend is undefined when yesterday's calendar day is incomplete or holds no bolus, when fewer than three of the previous seven days are complete, or when the window lies outside the reconstructed delivery span
- other: 0 windows
