# Action-balance outcome proxy versus glucose

73 users, 57,771 windows. Proxy = ΔBG / (ΔIOB + suggested SMB + ∫(suggested temp−profile basal)). IOB is model-derived and suggestions may differ from enacted delivery. This is not an independent physiological ISF. Ratio = proxy divided by each user's profile ISF.

Implied k: independent **-0.36**, loop-model -0.16, quartic 1.29 (k>0 = falls with glucose).

The action-balance outcome proxy is flat-to-rising with glucose (k=-0.36). Agreement with the loop-prediction proxy does not establish physiological ISF because both depend on model-derived IOB and closed-loop delivery.
