There are five stages, and the work stands between the third and the fourth. The replay on recorded histories was run on 138 people. It showed the candidate asking for 1.38 to 1.44 times the profile’s correction insulin, and it is descriptive with no pass rule. The second stage is the publication’s own measurement on AndroidAPS and Trio records, and it has no result to report yet. The simulation ran for two simulated months, as the last three slides covered. Shadow running is the current stage, with the code written and no records yet. Use comes last, on the author’s device first and on released lines after that, once shadow running has passed. The way back at every stage is the mode selector, because the existing modes stay in the code unchanged and remain the default.
