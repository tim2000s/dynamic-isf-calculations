Units of insulin for the worked person, with a profile ISF of 50 and 40 U a day on default settings.

Sensitivity is hard to picture, so here it is as a correction dose. From 150 mg/dL the curve asks for 1.11 units against the profile’s 1.00, which is a small difference. From 300 it asks for 9.62 against the profile’s 4.00 and AndroidAPS’s 8.29. That’s the steepness of the published curve showing up as insulin. I should be clear this is arithmetic on the sensitivity alone. In a running loop the IOB and the predictions come afterwards, and they decide what’s delivered, so these aren’t the doses anyone would get in one go.
