The existing modes stay the default throughout.

These are the things I’d like a view on, and they’re questions for the people who maintain AndroidAPS and Trio more than for me. The first is whether there’s appetite for one shared definition of this mode, with shared test vectors, given the two systems currently return values 42% apart for the same person at 200 mg/dL on defaults. The second is what Trio’s limits should do for a mode whose curve sits outside them for most of its range. The third is the anchor. The last is whether either project would be willing to carry the shadow value on its dev line, because records from real use are what the next stage needs, and nothing would dose from it while they’re collected.
