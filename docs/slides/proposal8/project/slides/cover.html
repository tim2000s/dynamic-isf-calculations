A proposed replacement for dynamic ISF based on Diabeloop’s published curve

The case for scaling the curve to the profile ISF in AndroidAPS and Trio

Tim Street, Diabettech, November 2026. Draft for discussion.

This deck accompanies the paper “An alternative proposal for dynamic ISF in open-source AID systems”. It proposes an additional dynamic ISF mode for AndroidAPS and Trio. The shape of the mode comes from a curve Diabeloop published in 2025, and its height comes from the person’s own profile ISF. Nothing in it has been tested in people or offered to either project. Views are invited before it goes further.
