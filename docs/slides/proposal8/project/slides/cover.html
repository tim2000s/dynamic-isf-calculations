A published curve for dynamic ISF

The case for scaling Diabeloop’s glucose curve to the profile ISF in AndroidAPS and Trio

Tim Street, Diabettech, November 2026. Draft for discussion.

This deck goes with the paper “An alternative proposal for dynamic ISF in open-source AID systems”. It’s a proposal for an extra dynamic ISF mode in AndroidAPS and Trio, where the shape comes from a curve Diabeloop published in 2025 and the height comes from the person’s own profile ISF. Nothing here has been tested in people, and nothing has been offered to either project yet. I’d like views on it before it goes any further.
