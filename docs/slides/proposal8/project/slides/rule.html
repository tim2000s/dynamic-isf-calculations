What’s the rule?

Sensitivity = profile ISF × curve at current glucose ÷ curve at 140 mg/dL

The shape is the publication’s

The published quartic is used as it stands, read between 100 and 380 mg/dL.

The height is yours

At 140 mg/dL the rule returns your profile ISF, whatever your daily dose.

140 is a choice

The publication’s reference is 180, which would make every dose 1.44 times smaller.

It’s an extra mode

The existing dynamic ISF modes stay in the code and stay the default.

The curve is from Romero-Ugalde et al. (doi:10.2337/db25-920-P).

So this is the whole proposal on one slide. Take the published curve at the current glucose, divide it by the curve’s value at 140 mg/dL, and multiply by the person’s profile ISF. At 140 you get your profile ISF back. Below that the rule gives a higher sensitivity and above it a lower one, following the published shape. Glucose is read between 100 and 380 mg/dL, so below 100 the value at 100 is used and above 380 the value at 380. The 140 anchor is a modelling choice of mine. The publication’s own reference is 180, and anchoring there would make every dose 1.44 times smaller. It’s offered as an alternative mode beside the ones people already use.
