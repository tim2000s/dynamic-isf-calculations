The proposed rule

Sensitivity = profile ISF × curve at current glucose ÷ curve at 140 mg/dL

Shape from the publication

The published quartic is used as it stands, read between 100 and 380 mg/dL.

Height from the profile ISF

At 140 mg/dL the rule returns the person’s profile ISF, whatever their daily dose.

Anchor at 140 mg/dL

The anchor is a modelling choice. The publication’s reference is 180 mg/dL, which would make every dose 1.44 times smaller.

An additional mode

The existing dynamic ISF modes stay in the code and remain the default.

The curve is from Romero-Ugalde et al. (doi:10.2337/db25-920-P).

The rule takes the published curve at the current glucose as a ratio to its value at 140 mg/dL and multiplies the profile ISF by that ratio. At 140 mg/dL it returns the profile ISF. Below 140 it gives a higher sensitivity and above 140 a lower one, following the published shape. Glucose is read between 100 and 380 mg/dL, so the value at 100 is used below 100 and the value at 380 above 380. The 140 mg/dL anchor is a modelling choice. The publication’s own reference is 180 mg/dL, and anchoring there would make every dose 1.44 times smaller. The rule is offered as an alternative mode beside the existing ones.
