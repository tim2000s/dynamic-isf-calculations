# Audit of the Dynamic ISF investigations

16 September 2026

## Scope

This audit reviewed the Dynamic ISF equation replay, TDD reconstruction, outcome comparisons,
effective-ISF estimators and glucose-shape analyses in this repository. It also reviewed the
physiological question against controlled human studies.

The intended questions were:

1. What values do V1 and V2 calculate from the same glucose and TDD history?
2. Does observed glucose behaviour support an ISF that changes with current glucose or recent TDD?
3. Can the observational data identify a physiological relationship between glucose and insulin
   sensitivity?
4. Could residual carbohydrate absorption explain part of the apparent relationship?

The first question is answered directly. The repository provides useful evidence for the second
and fourth questions, subject to the limitations below. The third question is not identified by
these data because insulin delivery, starting glucose and subsequent glucose movement all respond
to the same controller.

## Equation implementation

The executable implementation in `inv008/dynisf.py` uses:

```text
V1: ISF = 1800 / (TDD × ln(BG_adj/divisor + 1))
V2: ISF = 115000 / (TDD² × ln(BG_floor/divisor))
```

V2 is the author-confirmed form. It has no `+1`. The glucose floor is `divisor + 1`, which prevents
the logarithm reaching zero. The standard rapid-acting configuration used by this investigation
has a divisor of 75 mg/dL and a floor of 76 mg/dL. The divisor is a configuration input rather than
a universal glucose threshold.

The original investigation plan and `dynamic-isf-method-paper.md` described an earlier V2 with a
`+1` term. That description was wrong. The stored replay and same-window results were generated by
the no-`+1` Python implementation, so the numerical V2 findings do not require recalculation for
this correction.

The equation tests cover the two TDD-blend branches, glucose cap, V2 floor, vectorised behaviour
and hand-calculated values. They establish internal arithmetic correctness. `inv008/verify_all.py`
uses the same mathematical assumptions and is therefore a consistency check rather than an
independent device validation.

## What each analysis establishes

| Analysis | Intended test | Audit finding |
|---|---|---|
| Equation replay | Values V1 and V2 would calculate from recorded inputs | Valid counterfactual calculation, with the data limitations below |
| Device ISF validation | Agreement between replay and logged ISF | Partial validation. Eighteen users were available and the median log correlation was 0.595. The replay is not an exact device reproduction |
| Same-window head-to-head | Which candidate ISF best rescales the loop's IOB prediction | Valid comparison of candidate scalings within the loop prediction model. It is not an independent measurement of physiological ISF |
| Gradient glucose fit | Whether a glucose curve improves prediction after fitting each person's level | Useful negative predictive result. Random folds contain overlapping four-hour windows, so uncertainty and test-set independence are overstated |
| Overnight drop divided by starting IOB | Glucose change per unit of insulin | Descriptive outcome ratio. Continuing basal, boluses, temporary basal changes, endogenous glucose production and counter-regulation are omitted from the denominator |
| Delta-IOB regression | ISF from change in IOB over 30 minutes | Does not identify absorbed insulin. New delivery during the interval changes IOB, and delivery is chosen in response to glucose |
| Action-balance estimator | Insulin acting from delta IOB plus suggested SMB and temporary basal | Model-dependent. IOB already embeds an insulin-action model, and suggestion fields are not proof of enacted delivery |
| Post-COB comparison | Whether apparent insulin effect remains lower after COB reaches zero | Credible within-person association. It is consistent with residual absorption, but timing and closed-loop delivery remain alternative explanations |
| Entered ISF against TDD | Relationship between settings and TDD | Valid descriptive settings relationship. It is partly circular because ISF settings are commonly derived from TDD rules |

## Data and reconstruction limits

The replay includes bolus insulin and temporary-basal delivery where those records exist. Algorithmic
basal changes are dosing information and are not interchangeable with scheduled basal. This matters
for AID systems that deliver corrections mainly through temporary basal.

The AAPS v6 export used here does not contain temporary-basal records. Its reconstructed TDD therefore
uses scheduled basal and is incomplete for that cohort. Calendar-day totals are also formed on UTC
day boundaries, whereas AndroidAPS uses local calendar days. These differences prevent an exact
device-level replay for affected users.

The main analyses fix the divisor at 75 because insulin type was not reliably available for every
person. This is the standard rapid-acting configuration requested for the comparison. It should not
be described as a personalised replay of each person's insulin setting.

## Outcome-selection and closed-loop bias

Several analyses reject a four-hour window when any later 15-minute glucose rise exceeds a threshold.
This filter uses the outcome to decide whether the window enters the analysis. It preferentially
retains flat or falling glucose and can create a glucose-dependent result even when it removes some
carbohydrate-affected periods. Results using this screen are sensitivity analyses rather than
unbiased estimates of insulin action.

Closed-loop insulin delivery is confounded by indication. Higher or rising glucose causes more
bolus insulin or temporary basal, while the same high starting value tends to fall through glucose
effectiveness, renal loss and regression to the mean. A regression cannot reliably assign the fall
between insulin and these non-insulin processes when their predictors move together. The repository's
own `decompose_sensitivity.py` detects this failure: IOB and starting glucose are collinear, and the
fitted ISF collapses to a clinically implausible value.

The stored standard errors also treat many overlapping windows as though they were independent.
User-level summaries reduce the effect, but conventional window-level confidence intervals and
random cross-validation remain too narrow.

## Findings that remain supported

The direct equation comparison is supported. On the selected common windows, static ISF and the
loop's own calibrated ISF predicted the recorded endpoint more closely than either Dynamic ISF
equation. The reported median absolute errors were 20.3 mg/dL for static ISF, 18.6 mg/dL for the
loop value, 24.6 mg/dL for V1 and 49.7 mg/dL for V2. These figures compare candidate scalings of the
same loop prediction. They do not measure the causal effect of changing the controller.

The fitted glucose-shape work found no material predictive gain after each person's magnitude was
calibrated. The best shared power exponent was zero, and the nested analysis reported a median gain
of 0.0 mg/dL. This is evidence that the cohort did not support a deployable glucose-only ISF curve
within the tested prediction model.

The post-COB analysis found lower apparent insulin effect immediately after announced COB reached
zero, followed by partial recovery. Together with the difference between carb-announcing and
unannounced-meal patterns, this supports residual carbohydrate absorption as a plausible contributor
to apparent low sensitivity at high glucose. The analysis does not estimate what proportion of the
original Dynamic ISF signal came from carbohydrate.

The data do not establish a universal `ISF = K/sqrt(TDD)` physiological law. The reported exponent
and constants depend on estimators that do not isolate insulin action. They remain exploratory
descriptions of this cohort and should not be used as dosing constants.

## Physiological evidence

Insulin sensitivity varies within a person. Controlled studies support effects from circadian
hormones and sleep restriction. Day-to-day variation is measurable, while menstrual-cycle
effects differ between people and studies:

- Perriello and colleagues measured about 25% lower peripheral glucose utilisation and about 30%
  higher hepatic glucose production during the dawn period in 12 people with type 1 diabetes
  ([Diabetologia, 1990](https://pubmed.ncbi.nlm.nih.gov/2406181/)).
- One night of partial sleep restriction reduced insulin sensitivity in a small clamp study of
  adults with type 1 diabetes ([Diabetes Care, 2010](https://pubmed.ncbi.nlm.nih.gov/20357381/)).
- Repeated insulin-sensitivity tests found a 13% day-to-day coefficient of variation in 30 people
  with type 1 diabetes. The same study found no significant average difference between follicular
  and luteal phases ([Diabetic Medicine, 1995](https://pubmed.ncbi.nlm.nih.gov/7758258/)).
- A five-person pilot found no significant average phase difference in insulin sensitivity, although
  three participants had lower sensitivity in the luteal phase. Glucose effectiveness increased
  significantly ([Diabetes Technology & Therapeutics, 2007](https://pubmed.ncbi.nlm.nih.gov/17425444/)).

Current glucose is a poor substitute for those mechanisms. At fixed insulin, absolute glucose
disposal rises as glucose rises. This glucose mass-action effect was measured directly by Fink and
colleagues ([Metabolism, 1992](https://pubmed.ncbi.nlm.nih.gov/1640870/)).
Mitrakou and colleagues found that an apparent increase in a glucose-based sensitivity index during
hyperglycaemia disappeared after correcting for mass action
([Diabetes, 1992](https://pubmed.ncbi.nlm.nih.gov/1639939/)). The minimal-model literature separates
insulin sensitivity from glucose effectiveness for the same reason
([Bergman and colleagues, 1989](https://diabetesjournals.org/diabetes/article/38/12/1512/9005/Toward-Physiological-Understanding-of-Glucose)).

Chronic hyperglycaemia also does not imply a simple immediate glucose-to-resistance function. A study
comparing type 1 diabetes with GCK-MODY found preserved muscle insulin sensitivity in GCK-MODY despite
similar hyperglycaemia. Insulinaemia, rather than glycaemia, was associated with lower sensitivity
([Gregory and colleagues, 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6692813/)).

The physiological literature therefore supports genuinely variable insulin sensitivity. It does not
validate current glucose and recent blended TDD as a deterministic measurement of that sensitivity,
or the V1 and V2 functional forms. At high glucose, greater absolute disappearance can occur without
a change in insulin sensitivity. This mechanism can produce the opposite observational pattern from
the one assumed by Dynamic ISF.

## Audit verdict

The Python implementation correctly evaluates the intended V1 and V2 equations for the configured
inputs. The replay answers what the equations calculate. Its TDD reconstruction is incomplete for
some cohorts and is not an exact reproduction of every device.

The outcome analyses show that neither Dynamic ISF equation improved prediction in the selected
cohort and that a fitted glucose term added little after calibration. Those are supported predictive
findings. The data also support residual carbohydrate as a plausible source of some apparent
glucose-dependent sensitivity.

The repository does not identify the physiological effect of glucose or TDD on insulin sensitivity.
Claims of a universal square-root TDD law, a model-independent effective ISF, or proven high-glucose
insulin resistance should be withdrawn. A physiological Dynamic ISF phenomenon remains possible,
but the reviewed evidence does not validate V1, V2 or any single glucose-by-TDD surface.
